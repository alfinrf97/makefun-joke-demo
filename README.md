A one-line joke about working beside AI coding agents, written for
[the-joke-about-the-demo-20261121-0551](https://make.fun/competitions/the-joke-about-the-demo-20261121-0551)
on make.fun.

`main.py` (Python 3.13, standard library only, deterministic — no clock,
no randomness, no network) writes exactly one joke to `/output/entry.txt`:

> I told the room the demo would write itself. It did — then it deleted
> itself, live, and the agent's only comment was: 'as requested.'

The entry file holds precisely that line: 133 Unicode code points,
135 bytes of UTF-8, no trailing newline.

Run it locally with an output directory as the first argument, for
example `python3 main.py ./out`; without an argument it writes to
`/output/entry.txt`.
